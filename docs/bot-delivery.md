# Видача пака матеріалів через бот Zenedu

Створено 22.11.2026. Перший продукт у боті: пак матеріалів з часів для викладачів, 390 грн.

## Два боти

| Бот | Для чого | Де налаштовується |
|---|---|---|
| `@engtutors_bot` «Англійська легко від Engtutors» | Оплата, видача файлів та інструкцій. Один бот на всі продукти проєкту | Zenedu, воркспейс з ботом 10851 |
| `@eng_tutors_bot` «English Tutors Platform» | Тільки вхід на платформу (deep link `/start <token>`) | Код платформи, `src/app/api/telegram/webhook` |

## Як покупець отримує доступ

1. Кнопка на посадці `engtutors.vercel.app/pack` → пряма оплата WayForPay → стандартна сторінка Zenedu «дякуємо» з кнопкою в бот `@engtutors_bot` (свої тексти на ній тільки на тарифі Pro) → у боті оплата прив'язується до Telegram-акаунта.
2. Zenedu дає підписнику продукт «Пак матеріалів з часів англійської» і одразу надсилає 4 повідомлення (нижче).
3. Zenedu шле вебхук `product.subscriber.added` на `https://engtutors.vercel.app/api/zenedu/webhook` (вебхук воркспейсу 161). Платформа перевіряє підпис і створює або вмикає учителя з Telegram ID покупця.
4. Покупець тисне «Відкрити платформу» → «Увійти через Telegram» → `@eng_tutors_bot` → Start. Telegram ID той самий, учитель уже активний, вхід проходить.
5. Повернення (`order.refunded`) вимикає учителя й завершує його сесії.

Якщо людина зайшла на платформу раніше за вебхук, вона бачить «доступ ще не активовано» з підказкою зачекати хвилину й увійти ще раз.

## Як замінити картинку чи файл у повідомленні

Файли кроків живуть у Telegram. Запит `POST /api/v1/bot/10851/telegram-files` з порожнім тілом → бот чекає одне повідомлення (файл або альбом) від власника → файли з'являються в `GET …/telegram-files` → `PATCH` кроку з `telegram_file_ids` і `settings.attach_file: true` (текст стає підписом, до 1024 символів). Фото й документ в одному повідомленні Telegram не поєднує, тому PDF іде окремим кроком. Обкладинки 1280×640 збираються з `design/bot-cover/*.html` через headless Chrome.
