# Лендинг: як влаштовано

- Сторінка: `src/app/page.tsx` (корінь домену, публічна). Компонент: `src/components/landing/Landing.tsx`.
- Усі тексти: `src/config/landing.ts`. Заглушки в квадратних дужках. Посилання на бот покупки — `buyUrl` там само.
- Стилі: блок `/* landing */` наприкінці `src/app/globals.css`. Токени теми спільні з платформою (світла/темна).
- Секції по порядку: hero → problem → inside → demo (справжня картка і таймлайн з контенту) → for-whom → author → pricing → faq → final → footer.
- Доступ: у `src/proxy.ts` корінь `/` публічний, решта платформи закрита логіном. Шапка платформи на лендингу не показується (`TopBar.tsx`).
- Кнопка «Увійти» веде на `/login`; для того, хто вже увійшов, вона стає «Відкрити платформу».
