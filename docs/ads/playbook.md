Живой документ. Обновляется автоматически облачной рутиной, которая раз в два дня читает эталонный аккаунт и дописывает новые наблюдения. Правила ниже выведены из действий таргетолога, а не из теории. Каждое правило помечено датой, когда оно подтверждено в последний раз.

Эталонный аккаунт: ai.sashka (ID 1098053615857576), продукт «Воркшоп по AI-мультиках» за 390 грн. Таргетолог в журнале: Михайло Гунза.

Журнал наблюдений по датам: [log.md](log.md). Второй, масштабный подход другой команды на тот же продукт: [playbook-scale.md](playbook-scale.md).

## 1. Структура кампании

Схема «кампания = пак» закончилась: 30.09 выключена последняя её кампания `VIDEOPACK2_TEST2`, и её пак в тот же вечер пересобран группой `wide1_VIDEOPACK2_tessék` внутри `GLOBAL1`. (подтверждено 2026-10-03; изменено 2026-10-01: кампаний-паков больше нет ни одной, граница кампании окончательно = продукт; изменено 2026-09-29: до 28.09 кампания была одна; граница кампании — продукт, граница группы — пак; прежняя формулировка «одна кампания на всё» верна только пока продукт был один; изменено 2026-09-27: схема «кампания = пак» прожила с 09.09 по 25.09 и была разобрана за один вечер)

(изменено 2026-09-23: прежняя формулировка «на 20–24-м часе» описывала только первый из двух сроков)
