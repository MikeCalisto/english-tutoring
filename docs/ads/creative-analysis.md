# Анализ эффективности креативов: модель таргетолога (Миша Гунза)

Источник: таблица таргетолога от 2026-09-19 и его видеопояснение от 2026-09-20 (транскрипт внизу). Эту модель анализа мы перенимаем для своих запусков: таблица заполняется раз в 1–2 недели, при больших бюджетах раз в неделю.

## Принцип

«Продуктовый подход тестирования»: берётся один концепт, делается 3 и больше вариаций, они заливаются в одну кампанию. Единица анализа не кампания, а креатив-лидер внутри пака. Главный показатель один: CPS, цена продажи (Cost Per Sale).

## Колонки таблицы

| Колонка | Что писать |
|---|---|
| Кампания | Имя пака (слово-метка из нейминга кампании) |
| Тип | `S` статика, `V` видео. Звёздочка `*` = креатив собран нейросетью-монтажёром (у него это Clova / Jinjin), без звёздочки = ручной монтаж |
| Тип контента | Подвид: «пробивающая статика», «нормальная статика», «видео + плашка без озвучки», «классик видео со спикером», «100% закадр» |
| Смысл | Ключевая мысль креатива-лидера, цитата первой фразы или хука |
| Лидер | Файл креатива, который принёс больше всего покупок внутри пака |
| Траты | Расход пака за период |
| Покупки | Количество покупок |
| CPS | Траты / Покупки |

Шапка таблицы: период («9–19 сентября 2026»), общий расход и общее число покупок за период.

## Четыре среза анализа

1. **Статика против видео.** Какой формат даёт дешевле продажу.
2. **Ручной монтаж против AI-монтажа.** Есть ли смысл использовать нейросеть для сборки креативов.
3. **Смыслы.** У креативов с наибольшим числом покупок выписывается заложенный смысл, чтобы понимать, какая мысль продаёт, и повторять её в новых паках. Самый важный срез.
4. **Углубление, когда таблица вырастет.** Например, живая озвучка против робота, или другие детали, по которым захочется разобраться.

## Как это ведём мы

- В репозитории таблица по нашему продукту будет в этом же файле, отдельным разделом, период за периодом.
- Автоматически (рутина раз в два дня) заполняются: имя пака, тип S/V, смысл по тексту объявления, траты, покупки, CPS. Вручную дописываются: звёздочка AI-монтажа, подвид контента, лидер и смысл видео, потому что из API этого не видно.
- Раз в 1–2 недели по таблице делаются выводы по четырём срезам и уходят в плейбук.
